## Faro 1.0.0

Faro の最初の正式版です。アプリの画面を Figma のように描き、その部品を C# / Java のコードに紐付けて動かせます。はじめての方は [はじめてガイド](https://github.com/thesilver0913/faro-editor/blob/main/docs/guide.md) からどうぞ。

The first stable release of Faro: draw your app's screens like in Figma, then bind their parts to your C# or Java code. New to Faro? Start with the [Getting Started guide](https://github.com/thesilver0913/faro-editor/blob/main/docs/guide.en.md).

### できること / What's in it

- **画面の作成**:Stack・Wrap・Grid・Overlay による絶対座標なしのレイアウト、コンポーネントとバリアント、トークン、Fluent / Material 3、UI の履歴
  **Screens**: layout without absolute positions (Stack, Wrap, Grid, Overlay), components and variants, tokens, Fluent / Material 3, UI history
- **コードとの紐付け**:イベント・プロパティ・書式・一覧(`Items`)・行の選択・画面への値渡し。切れた紐付けは赤いバッジと候補で直せ、C# では名前変更に追従
  **Bindings**: events, properties, formats, lists (`Items`), row selection, passing a value to a screen; broken bindings are flagged with suggestions, and C# renames follow
- **確認**:プレビュー、実データ表示(C#)、サイズ・ライト/ダークの並べ比べ、実行とホットリロード(C#)、デバッガー(C#: netcoredbg、Java: java-debug)
  **Checking**: preview, live data (C#), side-by-side sizes and light/dark, run with hot reload (C#), debugger (C#: netcoredbg, Java: java-debug)
- **その他**:AI チャット(Claude / OpenAI 互換)、Git、Android APK、コマンドパレット、日本語 / 英語の UI、自動更新、クラッシュ報告
  **Also**: AI chat (Claude / OpenAI-compatible), Git, Android APKs, command palette, English / Japanese UI, updates, crash reports

### 1.0.0-beta から / From the betas

- プロジェクトを開くと Faro.Runtime 1.0.0 への更新を案内します。/ Opening a project offers to update it to Faro.Runtime 1.0.0.
- 安定性の修正:画面を移るたびに溜まっていた紐付けの登録、壊れた保存データや faro.json、言語サーバーの異常な応答、ほかのプログラムがファイルを使用中のときにエディターが落ちる問題、更新時に未保存のコードが消える問題など。
  Stability fixes: bindings piling up on every navigation, damaged saves and faro.json, malformed language server output, files locked by other programs taking the editor down, unsaved code lost when installing an update, and more.

### 既知の制限 / Known limitations

- インストーラーは未署名です。Windows では SmartScreen の「詳細情報 › 実行」、macOS では右クリック › 開く が必要です。
  The installers aren't signed yet: on Windows use SmartScreen's "More info › Run anyway", on macOS right-click › Open.
- Java の Android ビルドは Linux のみ。Apple シリコンの Mac では C# のデバッガーが使えません。実データ表示は C# のみです。
  Java Android builds need Linux; the C# debugger isn't available on Apple silicon Macs; live data preview is C# only.
